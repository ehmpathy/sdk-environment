## what blocks

circular dependency in transitive dependency causes `test:lint:cycles` to fail.

## production deps

PRODUCTION CYCLE EXISTS via:
```

└── @ehmpathy/uni-time@1.10.0
    └── helpful-errors@1.5.3  ← has cycle
```

## package with cycle

| package | version | cycle location |
|---------|---------|----------------|
| helpful-errors | 1.5.3 | HelpfulError.js ↔ withHelpfulError.js |

helpful-errors@1.7.x has no cycle.

## root cause analysis

the MAIN blocker is `simple-in-memory-cache@0.4.0`:
- **installed version** (0.4.0) depends on `@ehmpathy/uni-time@^1.7.4`
- `@ehmpathy/uni-time@1.10.0` depends on `helpful-errors@1.5.3` (cyclic)
- **unreleased version** (0.4.1 on GitHub) switched to `iso-time` (no cycle)
- 0.4.1 has NOT been published to npm yet

## what needs to happen upstream

1. **simple-in-memory-cache** - publish 0.4.1 (already fixed on GitHub)
2. **@ehmpathy/uni-time** - upgrade helpful-errors from 1.5.3 to 1.7.x
3. **declastruct** - upgrade to helpful-errors 1.7.x
4. **test-fns** - upgrade domain-objects from 0.31.9 to 0.31.13+

once `simple-in-memory-cache@0.4.1` is published, upgrade here and prod cycle is gone.
devDependency cycles require the other upstream fixes.
