# 🌙 dream: rhachet init writes the host's home path into a tracked settings file

- kind = reseed
- owner = ehmpathy/rhachet (`rhachet init --hooks`, the claude settings writer)
- caught 2026-11-20

## .the cue that fired
the done gate of sdk-environment#18 ruled each uncommitted path of the rhachet 1.51 upgrade. `.agent/.actors/actor.via.repo=ambient/brain/.claude/settings.of.repo.json`, which its own `.gitignore` marks as tracked, ends in:

```json
"claudeMdExcludes": [
  "/home/camper/.claude/CLAUDE.md",
  "**/CLAUDE.local.md"
]
```

## .the gap, precisely
- the first entry is the absolute home dir of the box that ran `rhachet init`
- tracked, it leaks the os account name to every clone, and on any other box it excludes naught
- so each box that re-runs init rewrites the line, and the diff churns per host

## .the shape of the fix
write a home-relative form claude code expands (e.g. `~/.claude/CLAUDE.md`), or keep the exclude in a gitignored local layer (`settings.local.json`). clamp: a test that runs init under two `HOME` values and asserts byte-equal `settings.of.repo.json`.

## .why it is not done in this round
another repo's writer. sdk-environment#18 holds the `.claude` migration out until it lands (fulcrum F20).
