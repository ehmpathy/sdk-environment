# case=1 — a cold burst asks aws once

cells: s07 · f03 · l02; densest walk s07 × f05 × l02.

## narrative
a 36-core grove starts jest. 29 workers each call `getEnvironment()` within a few ms. worker 7 creates the lock dir first, records its pid in it, and calls `GetAccountInformation`. the other 28 find the lock and poll every ~50–100ms. aws throttles once; worker 7 backs off and retries. the 28 see a live pid in the lock and keep their wait. worker 7 writes the name to the cache file, then drops the lock. the 28 read the file. every worker returns `test`. aws saw one call.
