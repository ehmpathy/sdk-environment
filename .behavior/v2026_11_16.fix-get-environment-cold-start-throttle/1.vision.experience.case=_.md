### recognition — how a reply joins its class
the reply axis names classes; these rules decide which shape belongs to which, by shape and never by realm (a throttle from another copy of the sdk is still a throttle):
- throttle: name `TooManyRequestsException`, or `$metadata.httpStatusCode === 429` under any name; a 500, a credential error, and a non-error value are none (`isThrottleError`, all six cases)
- transient server fault: a throttle, or `$fault: 'server'` / a 5xx; an unknown host, a credential refusal, and a non-object are not (`isServerTransientError`)
- credential error: an absent, expired, or invalid credential, by name or message, from any realm; a throttle, a 5xx, a reset socket, a `TypeError`, and a non-object are not (`isCredentialError`)
- a mis-class changes retry-vs-surface (f05/f07 vs f11) or null-vs-surface (f09 vs f13), so each boundary is pinned on both sides
