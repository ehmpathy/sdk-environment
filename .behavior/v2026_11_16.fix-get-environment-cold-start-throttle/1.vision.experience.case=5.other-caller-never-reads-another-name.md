# case=5 — another caller never reads another's name

cells: s04 · s16.

## narrative
a dev runs the suite against the test account; the cache holds `acme-test`. then the dev exports prod creds and runs a one-off command. the command's access key differs, so its cache key differs. it finds no file for its key, asks aws, and gets `acme-prod`. it never reads `acme-test`. a wrong tier here could aim a test-tier action at prod, so isolation is a critipath, not a nicety.

## bdd [tn]
```
given a fresh cache written under access key A
  [t0] when a process with access key B reads the account name
    then it finds no cache for key B
    then it asks aws itself
    then it returns B's account name, never A's
```
