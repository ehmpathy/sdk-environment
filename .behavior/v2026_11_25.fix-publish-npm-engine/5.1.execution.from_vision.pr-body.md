## what
the tag publish upgrades npm to `npm@11`, not `npm@latest`, so it runs on the repo's node and the next release reaches npm.

- `.github/workflows/.publish-npm.yml` `verify oidc compat`: `npm install -g npm@latest` → `npm install -g npm@11`, and its echo line, word for word with the `cicd-package` practice in `declapract-typescript-ehmpathy`
- why: `npm@latest` is now 12.2.3, engine `^22.22.2 || ^24.15.0 || >=26.0.0`; `.nvmrc` is `v22.21.0`, so the install stops at `EBADENGINE`. every 11.x declares `^20.17.0 || >=22.9.0`, and 11.21.3 clears the `>= 11.5.1` oidc floor
- the 11.x line still ships patches (11.21.3, 2026-11-18), and npm 11 already published this job green on this node (v0.1.5, before npm 12 existed)

## proof before merge
the publish job runs only on a tag, so until now pr ci never exercised this line. `rhx verify.publish-npm-pin` (new, `.agent/repo=.this/role=any/skills/`) runs the step, read from the workflow, on the `.nvmrc` node.

- with the fix: `npm 11.21.3 runs on node v22.21.0, >= 11.5.1 for oidc` (exit 0)
- `--spec 12.2.3`: `✋ ConstraintError: npm@12.2.3 does not run on node v22.21.0`, `Required: {"node":"^22.22.2 || ^24.15.0 || >=26.0.0"}`, `Actual: {"npm":"10.9.4","node":"v22.21.0"}` (exit 2) — the v0.1.6 failure, reproduced by hand

its integration test runs in every pr's ci from now on, on purpose: it is the regression clamp for this defect class, so a later pr that puts back `npm@latest`, or a future 11.x that drops this node, goes red before a tag meets it. the skill honors the workflow's own guard (it skips where the node's npm is already >= 11.5.1, as the tag does).

- case1 reads the real workflow and installs from the registry, so a pr that puts back `npm@latest` (or moves `.nvmrc` out of the npm's range) goes red before merge, not at the tag
- case1 is the one registry call. every other verdict runs offline, in a temp repo on the test's own node, so neither a `.nvmrc` bump nor a dev host's node can flip it: an engine that excludes the node, npm below 11.5.1, prereleases and `+build`, an installed npm that cannot start or prints a notice, the skip path, a loose `.nvmrc`, the fnm path on a dev host, a quoted workflow line, the rhx call shape
- also snapped: an unpublished spec (against a local registry), an unreachable registry, an expression spec, `--help`, bad flags, and absent inputs (no git repo, workflow, upgrade line, `.nvmrc`, node, or fnm)
