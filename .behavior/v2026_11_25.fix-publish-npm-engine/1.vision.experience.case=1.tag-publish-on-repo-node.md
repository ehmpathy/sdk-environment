# 1.vision.experience.case=1.tag-publish-on-repo-node

the densest walk: merge → release pr → tag → runner → registry → consumer. six boundaries, one critipath.

## narrative

i'm the maintainer. last week i merged #18, the release tag went red, and npm still says 0.1.5. today i merge the one-line `fix(publish)` pr. a minute later a release pr titled `v0.1.7` appears; i merge that too. i open the tag's publish run and watch `verify oidc compat`: it says npm 10.9.4 is too old for oidc, upgrades to the latest 11.x, and moves on — no `EBADENGINE` this time. build, then publish with provenance, both green.

then i'm the crew on `declapract-typescript-ehmpathy`. i run `npm view sdk-environment version`, read `0.1.7`, bump the pin, and the cold-start fix from #18 is mine.
