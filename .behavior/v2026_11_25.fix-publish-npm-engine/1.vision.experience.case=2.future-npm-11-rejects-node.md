# 1.vision.experience.case=2.future-npm-11-rejects-node

the one sharp edge the pin still leaves open: an npm 11.x release raises its engine floor above `v22.21.0`. no published 11.x does this today; the spotlight shows it fails safe.

## narrative

i'm the maintainer. the first pr after that npm release goes red in ci: the `verify.publish-npm-pin` clamp (its case1 runs the workflow's own `npm install -g npm@11` on the `.nvmrc` node) prints `✋ ConstraintError: npm@11 does not run on node v22.21.0`, with npm's `Required` and `Actual` lines, and the fix line `bump .nvmrc into its range`. i bump `.nvmrc`, the pr goes green, and no tag ever meets the edge.

if a tag is cut with no pr between the npm release and the tag, the publish run meets it instead. a release tag's publish run goes red. i open it and the `verify oidc compat` step names the cause in one screen: `EBADENGINE`, the npm version it tried, `Required: {"node": "<range>"}`, `Actual: {"node":"v22.21.0"}`. no package was published, so npm holds no half-release. the fix is plain from the message: bump `.nvmrc` into the required range, merge, and the next release tag publishes.

## bdd sketch

```
    then the job stops before build and publish — npm holds no partial release
  [t1] when the maintainer bumps .nvmrc into the required range and merges
    then the next release tag publishes green
```
